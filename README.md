# SITE_BBK_TR redesign V1 — yerel önizleme

Canlı siteye yazılmaz.

## En kolay yol (Windows)

1. Bu sayfada yeşil **Code** düğmesi → **Download ZIP**
2. İndirilen ZIP'i bir klasöre çıkarın
3. PHP yoksa: https://windows.php.net/download  (PHP 8.x Thread Safe ZIP) → `C:\php` klasörüne açın
4. `START-PREVIEW.bat` dosyasına çift tıklayın
5. Tarayıcıda açılır: http://localhost:8080
